# 蓝牙耳机统一归类 8518.30

## 决定

所有客户的蓝牙耳机（含 TWS 耳机）统一按 8518.30 申报，不再按"无线通信设备"8517.62 申报。

## 背景

不同客户申报的编码不一致，同一款耳机在欧盟被两次查验，理由是归类和出口申报不符。

## 结果

向海关申请了预裁定并获批，之后三个月同类货物没有再因归类被查验。
