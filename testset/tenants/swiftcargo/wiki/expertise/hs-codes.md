# HS code classification

## Structure

- Digits 1–6: international Harmonized System, the same everywhere.
- China: 10 digits (the last 4 are national).
- EU: 8-digit CN code; TARIC adds 2 more for measures such as anti-dumping duties.
- US: 10-digit HTS.

## Rules of thumb

- Classify by what the product is (material, function), not by the buyer's use.
- Sets are classified by the item that gives the set its essential character.
- Parts go under the machine's heading only if they are solely or mainly for that machine.
- Examples: Bluetooth earphones 8518.30; lithium-ion laptop batteries 8507.60.

A wrong code at export and a different code at import is the most common reason for holds.
