# 工作区迁移与合并

## 有效做法

1. 确认两个工作区的管理员身份，以及哪个是保留的目标工作区。
2. 在源工作区用管理员账号做完整导出（Markdown + 附件）。
3. 在目标工作区导入，按原有目录结构放在一个新的顶层文件夹下。
4. 重新邀请成员，按原来的权限组设置访问范围。
5. 通知所有人：旧的分享链接会失效，外部分享需要重新生成。

## 常见坑

- 直接关闭源工作区的订阅，导致导出前变成只读、附件无法下载。出现过 3 次。
- 忘记提醒评论和 @提及 不会迁移，客户以为数据丢失。出现过 2 次。
