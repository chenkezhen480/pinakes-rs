Records something about the user that should shape later answers: a lasting preference ("reply to
me in Chinese", "always show amounts with tax", "以后别放表格") or a standing fact about them (the
role, region, site or accounts they now handle). Call it without being asked whenever the user
says one, even in passing in a message that asks something else. Not for instructions about the
current message only ("this time", "这次用表格"), or someone else's preferences.

- `statement`: the preference or fact in one or two sentences, in the user's terms.
- `entities`: optional ids of graph nodes or types it concerns, as `search` returned them.

It is filed for the user, in the background.
